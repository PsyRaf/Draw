# Draw

A local 2-player reaction game inspired by classic western quick-draw duels, built with **Godot 4**.

## How to Play

- Two players share one screen.
- Player 1 uses the top half.
- Player 2 uses the bottom half.
- Wait for the **SHOOT!** signal.
- Click your side as quickly as possible.
- Clicking too early gives the other player a point.
- First player to reach 5 points wins.

## Features

- Local 2-player gameplay
- Randomized countdown
- Reaction time tracking
- False-start detection
- Neon sci-fi visuals
- Sound effects and background audio

## Built With

- Godot 4
- GDScript

## How to Run

1. Download or clone this repository.
2. Open the project in Godot 4.
3. Run the main scene.

or Download APK for mobile.
